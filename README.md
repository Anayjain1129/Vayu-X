# Vayu-X
a quadcopter made from scratch!! this drone uses a F450 drone frame and uses mission planner for the firmware

# Features:-
- Uses Crossflight flight controller
- 1800 Kv BLDC Motors
- 4200 Mah battery 
- F450 Frame
- 40 AMP ESC
- Fs-i6b as radio transmitter

# Why did i made this?
I made this project to learn about aerodynamics and learn how things fly and how things goes up!!
